# 送迎表

送迎表を作る・管理するためのWebページです。サーバーは不要で、`index.html` をブラウザで開くか、GitHub Pages で公開すると使えます。

## 機能

- 日付ごとの送迎表（お迎え／お送り）を車両別に表示
- 利用者の利用曜日から、その日の送迎表を自動作成
- 車両ごとに運転手・添乗員を選択
- 時刻・場所・メモの編集、車両の付け替え、欠席の切り替え
- 定員超過の警告
- 利用者・車両・職員の登録
- 印刷（A4横）
- データの書き出し／読み込み（JSON）

## データの保存について

データは使っているブラウザ内（localStorage）に保存されます。端末やブラウザを変えるとデータは引き継がれません。
「データ」タブから書き出したファイルで、バックアップや移行をしてください。
