# 送迎表メーカー

放課後等デイサービスの送迎表を自動で作るWebページです。サーバーは不要で、GitHub Pages などで公開して使います。

## 主な機能

- 児童・学校（曜日ごとの下校時刻）・車両（定員・チャイルドシート数）・スタッフ（運転可否・勤務時間）の登録
- その日の利用・出勤をもとに、お迎え／送りの便を自動編成（運転手・添乗員も自動で割り当て）
- **1週間・1か月をまとめて作成**：期間内の毎日の送迎表を一度に作成。HUGの利用予定を取り込んだあと、その期間をそのまま作成できます
- **送迎の記録（「記録」タブ）**：実際の出発・到着時刻と乗った児童をスマホで記録。月ごとの児童別乗車回数（片道）の集計とCSV保存ができ、送迎加算の確認に使えます
- **スタッフごとの予定**：運転・添乗の担当便をスタッフごとに一覧表示・コピー
- 運行タイムライン、便ごと／児童ごとの表示、児童の便の付け替え
- 定員オーバー・時間の重なり・入室時間に遅れるなどのチェック
- 連絡用テキストのコピー、CSV（Excel用）の保存
- HUGなどから書き出したCSV・Excelの取り込み（児童の一覧・利用予定）

## データの保存

- claude.ai の Artifact として開いた場合：claude.ai に保存され、スタッフ間で共有されます。
- それ以外（GitHub Pages など）：この端末のブラウザ（localStorage）に保存されます。他の端末とは共有されません。
  「設定」タブの「データのバックアップ」でファイルに書き出し・読み込みができます。

## セキュリティ

- **パスコードによる暗号化**（「設定」タブ）：設定すると、端末に保存するデータとバックアップファイルを AES-GCM（PBKDF2-SHA256 60万回で鍵を作成）で暗号化します。
  開くたびにパスコードが必要になり、15分操作がないと自動でロックします。パスコードは保存しないため、忘れるとデータは取り出せません。
- **データの検査**：保存データ・バックアップファイル・共有データは、読み込むときに形式を検査し、不正な値は取り除きます（画面への埋め込み攻撃を防止）。
- **Content Security Policy**：スクリプトはこのサイトのファイルだけを実行し、外部への通信を禁止しています（外部はフォントのみ）。
- **Excelの読み込み**：SheetJS（`js/xlsx.full.min.js`, 0.18.5）を外部CDNではなくこのリポジトリから読み込み、画面と切り離したワーカー（`js/xlsx-worker.js`）の中だけで実行します。20秒で打ち切ります。
- **CSVの数式対策**：書き出すCSVで `=` `+` `@` などから始まる値は文字列として扱い、Excelで数式が実行されないようにしています。
- 他のサイトの中に埋め込まれた状態では動かないようにしています。
- 児童の本名は保存しません（HUG照合用には本名から作った暗号（ハッシュ）だけを保存）。

### 注意

- GitHub Pages で公開する場合、サイトのファイル（プログラム）は誰でも見られますが、児童などのデータは各端末のブラウザにしか保存されず、ネット上には出ません。
- 他の人も使う端末では、必ずパスコードを設定してください。
- Excelファイルの読み込みには、ファイルを直接開くのではなく https のページ（GitHub Pages など）で開く必要があります。
